# 스튜디오 Pro Tools 작업 SOP

> 이 문서는 교육용 예시 SOP입니다. 실제 스튜디오의 규칙이 아니며, 각자의 작업 기준에 맞게 고쳐 쓰세요.

## 세션 생성 규칙
새 세션은 항상 샘플 레이트 48kHz, 비트 심도 24비트, 파일 형식 WAV로 만든다. 세션 이름은 "프로젝트명_곡명_YYMMDD" 형식으로 짓고, 띄어쓰기 대신 밑줄을 쓴다. 세션 폴더는 외장 작업 드라이브의 "Sessions/프로젝트명" 폴더 안에 저장하며, 시스템 드라이브(바탕화면 등)에는 저장하지 않는다. 같은 곡을 크게 수정할 때는 덮어쓰지 않고 File > Save As로 이름 끝에 "_v2", "_v3"을 붙여 새 버전으로 저장한다.

## 녹음 전 체크리스트
녹음을 시작하기 전에 Playback Engine의 H/W Buffer Size를 128 샘플 이하로 낮춰 모니터링 지연을 줄인다. 연주자에게 가장 큰 소리로 연주하게 하고 입력 미터가 -12 dB에서 -6 dB 사이에서 피크가 나도록 프리앰프 게인을 맞춘다. 녹음할 트랙의 이름은 녹음 전에 "악기명_연주자"로 바꿔 두어 테이크 파일 이름이 자동으로 정리되게 한다. 녹음이 끝나고 믹싱을 시작할 때는 H/W Buffer Size를 1024 샘플로 다시 올린다.

## 납품 바운스 규칙
클라이언트 납품용 최종 믹스는 WAV, 48kHz, 24비트, 스테레오 인터리브드로 바운스한다. 파일 이름은 "곡명_Mix_v번호_YYMMDD" 형식으로 짓고, 수정본을 보낼 때마다 v 번호를 하나씩 올린다. 바운스 전에는 마스터 페이더 미터에서 클리핑이 없는지, 뮤트되거나 비활성화된 트랙이 빠지지 않았는지 확인한다. 바운스가 끝나면 파일을 처음부터 끝까지 한 번 들어 본 뒤에 납품 폴더 "Deliver/날짜"에 복사한다.
